# Driver Drowsiness Detection System

Real-time driver drowsiness detection using Python, OpenCV, MediaPipe Face Mesh, and a trained machine learning model.

## Features
- Webcam-based facial landmark detection
- Eye Aspect Ratio (EAR) analysis
- Alert and drowsy classification
- Audio warning when drowsiness is detected

## Run
Activate your virtual environment, install the required dependencies, and run:

```powershell
python 'demo_model_based copy.py'
```
