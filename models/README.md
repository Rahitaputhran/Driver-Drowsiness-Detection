# Models

Place the MediaPipe Face Landmarker task model here:

```text
models/face_landmarker.task
```

After training, the ML model will be written as:

```text
models/drowsiness_xgb.joblib
```

The optional CNN will be written as:

```text
models/eye_state_mobilenet.keras
```

Do not commit large binary models to Git unless you intentionally want to use Git LFS.
